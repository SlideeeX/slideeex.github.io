# guic::engine::Vertex
Структура описывает одну вершину геометрии для рендерера - позицию, координаты текстуры и цвет

## Поля

|Тип|Поле|Назначение|Метка|
|---|----|----------|-----|
|float|x|Координата по горизонтали (по умолчанию 0)|<span class="green-stable">stable</span>|
|float|y|Координата по вертикали (по умолчанию 0)|<span class="green-stable">stable</span>|
|float|u|Координата текстуры по горизонтали (по умолчанию 0)|<span class="green-stable">stable</span>|
|float|v|Координата текстуры по вертикали (по умолчанию 0)|<span class="green-stable">stable</span>|
|Color|color|Цвет вершины (по умолчанию `Color::Black`)|<span class="green-stable">stable</span>|
