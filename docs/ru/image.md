# guic::Image
Класс является ресурсом изображения - загружает картинку из файла и передаёт её рендереру. Наследует `engine::Resource`

## Поддерживаемые форматы

Изображения загружаются через stb_image. Формат определяется по содержимому файла, а не по расширению.

* PNG
* JPEG
* BMP
* GIF - только первый кадр, анимация не поддерживается
* TGA
* PSD - итоговое изображение, слои не читаются
* HDR - приводится к 8-битному формату
* PIC
* PNM - только бинарные PPM и PGM

Не поддерживаются: SVG, WebP, AVIF, TIFF и другие форматы. Для них изображение не загружается.

## Конструкторы

* `Image(const std::string& path)` - Конструктор для создания изображения из файла по пути `path`

## Методы

|Тип|Метод|Назначение|Метка|
|---|-----|----------|-----|
|engine::Bitmap*|createBitmap|Загружает пиксели изображения из файла и приводит их к RGBA32. Переопределяет `Resource::createBitmap()`|<span class="green-stable">stable</span>|
|Size|getSize|Возвращает размер изображения. Значение появляется после первой загрузки ресурса, до этого размер нулевой|<span class="green-stable">stable</span>|

Методы, унаследованные от `engine::Resource` (`load`, `unload`, `getRevision`, `isMetadataLoaded`), описаны на странице [Resource](resource.md).
