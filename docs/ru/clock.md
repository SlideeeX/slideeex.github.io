# guic::Clock
Класс является представлением таймера - измеряет время в миллисекундах по монотонным часам и позволяет запускать, останавливать и «перезапускать круг» таймера

## Конструкторы

* `Clock()` - Базовый конструктор для создания таймера

## Методы

|Тип|Метод|Назначение|Метка|
|---|-----|----------|-----|
|Uint64|getTime|Возвращает текущее время в миллисекундах|<span class="green-stable">stable</span>|
|void|startTimer|Запускает таймер. Если таймер уже запущен, ничего не делает|<span class="green-stable">stable</span>|
|void|stopTimer|Останавливает таймер, накопленное время сохраняется. Если таймер не запущен, ничего не делает|<span class="green-stable">stable</span>|
|Uint64|getTimer|Возвращает время таймера в миллисекундах: для запущенного таймера - текущее, для остановленного - накопленное|<span class="green-stable">stable</span>|
|Uint64|lapTimer|Возвращает прошедшее время таймера и сбрасывает его, после чего таймер продолжает отсчёт с нуля|<span class="green-stable">stable</span>|
