# guic::engine::GlyphEntry
Структура связывает кодовую точку символа с его глифом в атласе

## Поля

|Тип|Поле|Назначение|Метка|
|---|----|----------|-----|
|Uint32|codepoint|Кодовая точка символа (по умолчанию 0)|<span class="green-stable">stable</span>|
|Glyph|glyph|Глиф, соответствующий кодовой точке (см. [Glyph](glyph.md))|<span class="green-stable">stable</span>|
