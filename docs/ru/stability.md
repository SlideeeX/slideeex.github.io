# Пояснение к меткам

У каждой функции и метода в разделе «Публичный API» есть метка статуса стабильности:

- <span class="green-stable">stable</span> - поведение, скорее всего, не изменится.
- <span class="yellow-stable">beta</span> - может измениться.
- <span class="red-stable">unstable</span> - может измениться в любой версии, без гарантий.
