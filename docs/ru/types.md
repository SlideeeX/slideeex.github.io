# guic::Types
Файл задаёт псевдонимы числовых типов фиксированного размера. Методов и полей нет. <span class="green-stable">stable</span>

## Псевдонимы

* `Sint8`, `Sint16`, `Sint32`, `Sint64` - знаковые целые размером 8, 16, 32 и 64 бита (`int8_t`, `int16_t`, `int32_t`, `int64_t`)
* `Uint8`, `Uint16`, `Uint32`, `Uint64` - беззнаковые целые размером 8, 16, 32 и 64 бита (`uint8_t`, `uint16_t`, `uint32_t`, `uint64_t`)
* `Char32` - символ Unicode (`char32_t`)
