<h2 style="text-align: center;">Что такое Guic</h2>

Guic (Graphical User Interface Creator) — библиотека для создания графического пользовательского интерфейса. Его задача облегчить создание интерфейсов для ПО, позволить создавать их без разворачивания тяжёлых фреймворков, без зазубривания графических библиотек и без изучения единственно правильных архитектурных решений.

Guic работает на движке SDL, что позволяет использовать его в продакшене: интерфейс не будет лагать от пары картинок. Библиотека распространяется под лицензией LGPL-3.0 с исключением (Подробнее см. в поставляемом дистрибутиве), поэтому разрабатывать на ней коммерческое ПО можно с чистой совестью.

Guic выделяется интуитивной базой элементов-примитивов. Интерфейс собирается как конструктор: из простейших элементов строятся полноценные компоненты со своей логикой, из них — интерфейс любой сложности. Он развивается шаг за шагом: от простого фона приложения и меню выбора до сложных композитных структур. Встроенные инструменты помогают разработке, применяя распространённые паттерны интерфейсов.

Для отображения интерфейса нужен цикл, но Guic не заставляет долго размышлять над его заполнением. Элементы взаимодействия с пользователем могут содержать переданные лямбда-функции, что позволяет привязывать функционал вне основного цикла.

Библиотеку можно расширять собственными Resource, Event и Element. Движок обрабатывает всё, что пользователь выставляет в публичный и защищённый (public/protected) интерфейс наследника.
