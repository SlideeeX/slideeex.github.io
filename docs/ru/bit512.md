# guic::engine::Bit512
Класс является битовым набором на 512 бит. Используется как тип клавиш (`engine::Keys`). Все операции `constexpr`

## Конструкторы

* `Bit512()` - Создаёт пустой набор (все биты сброшены)
* `Bit512(Uint16 index)` - Создаёт набор, в котором установлен только бит с номером `index`

## Методы

|Тип|Метод|Назначение|Метка|
|---|-----|----------|-----|
|Bit512|operator~|Инверсия всех битов|<span class="green-stable">stable</span>|
|Bit512|operator\||Побитовое «ИЛИ» с другим набором|<span class="green-stable">stable</span>|
|Bit512|operator&|Побитовое «И» с другим набором|<span class="green-stable">stable</span>|
|bool|operator==|Сравнение с другим набором|<span class="green-stable">stable</span>|
|bool|operator!=|Сравнение "НЕ" с другим набором|<span class="green-stable">stable</span>|
|bool|empty|Проверяет, что все биты сброшены|<span class="green-stable">stable</span>|
|bool|any|Проверяет, что установлен хотя бы один бит|<span class="green-stable">stable</span>|
