# Создание окна

Для подключения Guic используйте заголовочный файл Guic.hpp - он содержит все основные определения для работы с библиотекой.

```cpp
#include <Guic/Guic.hpp>
```

Все элементы хранятся в именном пространстве guic, поэтому для удобства будем использовать using.

```cpp
using namespace guic;
```

Добавляем функцию main, и в ней создаём новое окно через класс Window, указывая его название и размер. Для размера используем Guic-класс Size.

```cpp
int main() {
    Window window("Как настроение?", Size(640, 480));

    return 0;
}
```

Изначально окно создаётся закрытым, поэтому открываем (При открытии оно будет показано автоматически).

```cpp
window.open();
```

Guic не управляет циклом программы, поэтому цикл создаём сами. Для условия работы цикла можно проверять, открыто ли окно.

```cpp
while (window.isOpen()) {
    
}
```

Для управления у окна есть две функции - настройка и отображение.
Настройка обрабатывает входящие события и запускает логику элементов, а отображение собирает все изменения и отправляет их в отрисовку.
Добавляем их в цикл в логичном порядке - сначала обработка логики, потом отрисовка:

```cpp
window.tune();
window.display();
```

Цикл съедает максимум ресурсов процессора, сколько может себе позволить. Поэтому для экономии ресурсов ставим в конце цикла задержку:

```cpp
guic_delay(10);
```

## Итоговый результат
```cpp
#include <Guic/Guic.hpp>

using namespace guic;

int main() {
    Window window("Как настроение?", Size(640, 480));
    window.open();

    while (window.isOpen()) {
        window.tune();
        window.display();

        guic_delay(10);
    }

    return 0;
}

```
