# Вывод картинки

Для вывода картинки можем взять код из предыдущего шага.

Картинка создаётся с помощью класса Sprite. При создании указываем его Rect - прямоугольник области,
где x и y - координаты спрайта, а width и height - размеры спрайта.
Вторым параметром укажем цвет морской волны через Guic-класс Color

```cpp
Sprite background(Rect(0, 0, 640, 480), Color("#1b4242"));
```

Для отображения спрайта нам нужно добавить его в Window
(Один и тот же элемент не получится добавить в разные окна - он будет именно перемещён)

```cpp
window.add(background);
```

Теперь можно скомпилировать код и увидеть, что фон морской волны установлен.
Если попытаться растянуть окно - области справа и снизу останутся пустыми,
т.к. наш фон рассчитан для окна 640х480, дальше он просто не рисуется

Но цветного прямоугольника мало - мы можем вывести изображение.
Класс Image не хранит в себе изображение, поэтому оно будет загружено в программу по необходимости автоматически.
Такое поведение свойственно любому ресурсному классу.

Создаём Image

```cpp
Image picture("kit.png");
```

Теперь создаём Sprite, немного подвинем его, но вместо цвета морской волны укажем наше изображение

```cpp
Sprite photo(Rect(100, 100, 140, 140), picture);
```

Ну и до кучи превратим его в круг. Наш спрайт имеет ширину 140. Значит, у круга диаметр тоже будет 140. Поэтому делим диаметр на 2 и получаем нужный радиус 70

```cpp
photo.setRadius(70);
```

Добавляем спрайт и запоминаем - теперь удалять picture нельзя. Сначала необходимо его выгрузить через рендерер: `window.getRenderer()->unload(picture);`. Если пропустить её, картинка останется в видеопамяти.

```cpp
window.add(photo);
```

## Итоговый результат
```cpp
#include <Guic/Guic.hpp>

using namespace guic;

int main() {
    Window window("Как настроение?", Size(640, 480));
    window.open();

    Sprite background(Rect(0, 0, 640, 480), Color("#1b4242"));
    window.add(background);

    Image picture("kit.png");
    Sprite photo(Rect(100, 100, 140, 140), picture);
    photo.setRadius(70);
    window.add(photo);

    while (window.isOpen()) {
        window.tune();
        window.display();

        guic_delay(10);
    }

    return 0;
}
```
