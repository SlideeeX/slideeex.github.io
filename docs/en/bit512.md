# guic::engine::Bit512
A bitset of 512 bits. Used as the key type (`engine::Keys`). All operations are `constexpr`

## Constructors

* `Bit512()` - Creates an empty set (all bits cleared)
* `Bit512(Uint16 index)` - Creates a set in which only the bit with number `index` is set
