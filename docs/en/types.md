# guic::Types
The file defines aliases for fixed-size numeric types. It has no methods or fields. <span class="green-stable">stable</span>

## Aliases

* `Sint8`, `Sint16`, `Sint32`, `Sint64` - signed integers of 8, 16, 32 and 64 bits (`int8_t`, `int16_t`, `int32_t`, `int64_t`)
* `Uint8`, `Uint16`, `Uint32`, `Uint64` - unsigned integers of 8, 16, 32 and 64 bits (`uint8_t`, `uint16_t`, `uint32_t`, `uint64_t`)
* `Char32` - a Unicode character (`char32_t`)
