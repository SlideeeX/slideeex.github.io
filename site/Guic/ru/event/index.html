    guic::Event

    Структура описывает событие ввода и окна - тип события, модификаторы клавиш, идентификатор окна и данные события

    Поля

    Тип Поле Назначение Метка
    EventType type Тип события (по умолчанию EventType::None) stable
    mods mods Состояние модификаторов клавиш в момент события stable
    Uint32 winId Идентификатор окна, в котором произошло событие (по умолчанию 0) stable
    Uint32 customId Идентификатор пользовательского события. Диапазон 100000–999999 зарезервирован за Guic, 0–99999 - для основной разработки stable
    std::vector filePaths Пути к файлам при событии перетаскивания файлов stable
    data data Данные события, содержимое зависит от type stable

    Перечисление Event::EventType

    Название Назначение Метка
    None Отсутствие события или неудачное распознавание stable
    Custom Пользовательское событие. Его идентификатор задаётся в customId stable
    KeyPressed Клавиша нажата stable
    KeyReleased Клавиша отпущена stable
    MouseMoved Мышь двинулась stable
    MouseButtonPressed Кнопка мыши нажата stable
    MouseButtonReleased Кнопка мыши отпущена stable
    MouseButtonClicked Клик: кнопка нажата и отпущена той же кнопкой мыши. Создаётся Guic, а не системой stable
    MouseWheelScrolled Прокручено колёсико мыши stable
    WindowClosed Окно закрыто stable
    WindowResized Окно изменило размер stable
    WindowMinimized Окно свернулось в панель stable
    WindowMaximized Окно развернулось на весь экран stable
    WindowRestored Окно восстановилось из панели или уменьшилось stable
    WindowMoved Окно сдвинулось stable
    WindowFocusGained Окно поймало фокус stable
    WindowFocusLost Окно потеряло фокус stable
    TextEntered Введён текст stable
    FileDropped В окно закинут файл stable
    WindowExposed Часть окна была повреждена, перекрыта или отображается снова stable

    Вложенная структура mods

    Название Назначение Метка
    shift Зажата любая клавиша Shift stable
    ctrl Зажата любая клавиша Ctrl stable
    alt Зажата любая клавиша Alt stable
    system Зажата любая клавиша System stable
    rshift Зажата правая клавиша Shift stable
    rctrl Зажата правая клавиша Ctrl stable
    ralt Зажата правая клавиша Alt stable
    rsystem Зажата правая клавиша System stable
    capslock Включён CapsLock stable
    numlock Включён NumLock stable
    scrolllock Включён ScrollLock stable

    Объединение data

    Объединение с данными события. Какое поле актуально, зависит от type:

    • key - клавиша key и флаг repeat. Флаги pressed и released Guic сейчас не заполняет
    • mouse - координаты x, y, смещение dx, dy, клавиша key и прокрутка wheel
    • click - позиции нажатия pressedX, pressedY, позиции отпускания releasedX, releasedY и клавиша key. Заполняется для MouseButtonClicked
    • window - позиция x, y и размер w, h окна. Флаг close Guic сейчас не заполняет
    • text - введённый текст в виде массива char[32]
    • file - количество файлов count. Guic сейчас не заполняет это поле: пути к файлам лежат в filePaths
